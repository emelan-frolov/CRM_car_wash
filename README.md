# 🚗 CRM система для автомойки

Полнофункциональная CRM система для управления автомойкой с визуальным расписанием боксов.

## 🎯 Основные возможности

- ✅ **Управление клиентами** - добавление, поиск по телефону, история заказов
- ✅ **Управление автомобилями** - база автомобилей, поиск по гос. номеру
- ✅ **Управление услугами** - настройка услуг, цен и длительности
- ✅ **Управление боксами** - настройка количества и названий боксов
- ✅ **Визуальное расписание** - интерактивный дашборд с временной шкалой
- ✅ **Создание заказов** - умная форма с автозаполнением данных
- ✅ **Отслеживание статусов** - ожидает, в работе, завершен
- ✅ **Анимация прогресса** - визуальное отображение выполнения заказа

## 🏗️ Технологии

### Backend
- **Python 3.x** - основной язык
- **Flask** - веб-фреймворк
- **SQLAlchemy** - ORM для работы с БД
- **PostgreSQL** - база данных
- **Flask-CORS** - поддержка CORS для API

### Frontend
- **React 18** - UI библиотека
- **React Router** - маршрутизация
- **Axios** - HTTP клиент
- **CSS3** - стилизация

## 🚀 Быстрый старт

### 1. Установка зависимостей

**Backend:**
```bash
cd backend
pip install -r requirements.txt
```

**Frontend:**
```bash
cd frontend
npm install
```

### 2. Настройка базы данных

1. Убедитесь что PostgreSQL установлен и запущен
2. Создайте базу данных `crm_car_wash` через pgAdmin
3. Запустите миграцию:
```bash
cd backend
python migrate_db.py
```

### 3. Запуск приложения

**Backend (в первом терминале):**
```bash
cd backend
python app.py
```
Или просто дважды кликните на `start_server.bat`

**Frontend (во втором терминале):**
```bash
cd frontend
npm start
```

### 4. Откройте в браузере

http://localhost:3000

## 🎨 Интерфейс

### Главная страница (Расписание)
- Визуальная таблица с боксами (строки) и временной шкалой (столбцы)
- Временная шкала: последние 2 часа + 4 часа вперед (интервалы 15 минут)
- Заказы отображаются как цветные карточки на временной шкале
- Красная пульсирующая линия показывает текущее время
- Анимация прогресса для заказов в работе

### Создание заказа
1. **Клиент** - поиск по телефону, автозаполнение или создание нового
2. **Автомобиль** - поиск по гос. номеру, автозаполнение или создание нового
3. **Детали заказа** - выбор услуг (множественный выбор), бокса и времени
4. Автоматический расчет общей стоимости и длительности

### Управление данными
- **Клиенты** - список всех клиентов с телефонами
- **Автомобили** - база автомобилей с гос. номерами
- **Услуги** - настройка услуг, цен и длительности
- **Заказы** - полный список заказов с фильтрацией
- **Настройки** - управление боксами (добавление, редактирование, удаление)

## 🐛 Решение проблем

### CORS ошибка в браузере
**Проблема:** `Access to XMLHttpRequest blocked by CORS policy`

**Решение:** Backend сервер не запущен. Запустите `python app.py` или `start_server.bat`

### Боксы не отображаются
**Проблема:** На главной странице пусто

**Решение:** 
1. Проверьте что backend запущен
2. Откройте http://localhost:5000/api/boxes
3. Если пусто, запустите `python migrate_db.py`

### Ошибка подключения к БД
**Проблема:** `Connection refused` или `could not connect to server`

**Решение:**
1. Убедитесь что PostgreSQL запущен
2. Проверьте данные подключения в `app.py`
3. Создайте базу `crm_car_wash` если её нет

## 📝 API Endpoints

### Клиенты
- `GET /api/clients` - список всех клиентов
- `GET /api/clients/search?phone=XXX` - поиск по телефону
- `POST /api/clients` - создать клиента
- `PUT /api/clients/:id` - обновить клиента
- `DELETE /api/clients/:id` - удалить клиента

### Автомобили
- `GET /api/cars` - список всех автомобилей
- `GET /api/cars/search?license_plate=XXX` - поиск по номеру
- `POST /api/cars` - создать автомобиль

### Услуги
- `GET /api/services` - список всех услуг
- `POST /api/services` - создать услугу

### Боксы
- `GET /api/boxes` - список всех боксов
- `POST /api/boxes` - создать бокс
- `PUT /api/boxes/:id` - обновить бокс
- `DELETE /api/boxes/:id` - удалить бокс

### Заказы
- `GET /api/orders` - список всех заказов
- `GET /api/orders/schedule` - заказы для расписания (±6 часов)
- `POST /api/orders` - создать заказ
- `PUT /api/orders/:id` - обновить заказ

### Системные
- `GET /api/health` - проверка здоровья сервера
- `GET /api/settings` - получить настройки
- `POST /api/settings` - обновить настройки
